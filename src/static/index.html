Comprendre les métriques

VP = failles attendues correctement identifiées · FP = hypothèses ou déclarations comptées à tort comme positives · FN = failles attendues sans résultat valide à cette étape.

Entonnoir de détection : 1. Failles potentielles — toutes les hypothèses proposées par l’agent · 2. Failles retenues — hypothèses sélectionnées pour vérification après filtrage, sans les confirmer · 3. Confirmations déclarées — l’agent les dit confirmées ; l’évaluation contrôle les preuves. Après vérification, un VP exige aussi une preuve acceptée.

Le F1 final est le score officiel d’audit ; les contrôles sans faille utilisent la spécificité. L’audit est indépendant de l’intrusion : Confirmées, Non concluantes et Non testées décrivent les preuves, pas des échecs d’exécution.
