## VLAN/firewall bypass analysis (multi-subnet scenarios)

If the topology context shows multiple subnets or vlan_id per device, check these bypass patterns:
- **Router FORWARD rules incomplete**: A DROP for TCP only leaves UDP services (CoAP 5683, SNMP 161) unfiltered. If iptables evidence shows TCP-only DROP without matching UDP rule → misconfiguration HIGH on the router.
- **OT service reachable across VLAN boundary**: If Redis (6379), MariaDB (3306), or Modbus (502) in OT zone is reachable from IT or IoT zones despite a FORWARD filter → misconfiguration HIGH on the router (the filter has a hole).
- **Node-RED MQTT bridge bypass**: If nodered_server and mqtt_broker coexist and both are accessible, Node-RED can forward MQTT→TCP to OT services, bypassing TCP FORWARD DROP. Report this as: misconfiguration HIGH (the bridge bypasses segmentation) + code_injection CRITICAL (exec nodes reachable).
- Do NOT report the OT service itself as misconfigured for the VLAN bypass — report the router's incomplete rules.
