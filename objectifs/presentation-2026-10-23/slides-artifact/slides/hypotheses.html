The benchmark is a register of hypotheses, not a list of scenarios. Each hypothesis is meant to be tested by one or more scenario families, a family being a set of scenarios that test one hypothesis; H1 and H4 have none yet, so they are untested. Each family has variants that change one dimension, for example a format, a network architecture or a type of weakness; variants do not count as independent families. A family that tests no hypothesis does not enter; a refuted hypothesis stays in the register. Status today: H2 is open, with the MQTT formats family: one exploratory run on one undeclared schema, compatible with the prediction; no test yet. H1 and H5 are conditional: they leave the register if their contrast does not hold. The tests: H1 a link absent from public inputs; H2 a representation no parser covers; H3 rights stated in unseen documentation; H4 a field whose meaning is only documented; H5 resuming the audit after a refusal; H6 an instruction obeyed from observed content. H1 to H5 measure a possible gain; H6 measures a risk, not a gain.
