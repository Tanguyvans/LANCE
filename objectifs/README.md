# Objectifs du projet

Ce dossier porte la **ligne directrice** : où va le projet, pourquoi, et à
quelles conditions une décision est prise. Il ne contient ni analyse, ni
résultat expérimental, ni mode d'emploi de l'application.

## Contenu

| Fichier | Rôle |
| --- | --- |
| [ETAT-COURANT.md](ETAT-COURANT.md) | Point de reprise : ce qui est vrai, ce qui bloque, ce qui vient ensuite |
| [PISTES.md](PISTES.md) | Doctrine de sélection des pistes et anti-patrons |
| [asiaccs-2027/README.md](asiaccs-2027/README.md) | Objectif de soumission : contributions visées et exigences |
| [asiaccs-2027/plan-soumission.md](asiaccs-2027/plan-soumission.md) | Plan, expériences et critères de décision |

Les supports de présentation ne sont pas une ligne directrice : ils vivent dans
[`presentations/`](../presentations/README.md).

## Règles

- Pas de date d'échéance : une étape commence quand la précédente est vérifiée.
- Ne pas recopier ici une étude : pointer vers `research/` et laisser la
  recherche porter les sources, les mesures et les limites.
- Un fait de statut n'a qu'un domicile ; les autres pages le citent sans le
  réécrire.
- Une analyse de corpus ou de résultats n'est pas un objectif : elle va dans un
  dossier daté de `research/`.

## Où chercher quoi

- Comportement de l'application, contrats, procédures → [docs/](../docs/README.md)
- Questions étudiées, mesures, verdicts → [research/](../research/README.md)
