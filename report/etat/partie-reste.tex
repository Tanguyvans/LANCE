\section{What remains}
\label{sec:reste}

\subsection{What the project can assert, and what it cannot}

Four assertions are defensible, each with its limit. An audit produces verifiable
traces: every tool call is archived and referenced, and the run stops when its
evidence log cannot be written --- but the guards are application-level. A harness
can run outside the laboratory, without broker or model, under a guard that
declares its blind spots --- but it instruments and measures nothing. A third
script arm absorbs a gain attributed to the model on the most documented trial ---
but that holds for eight fixtures and one property. The corpus is mostly
detectable by signature, which makes a null difference expected by construction ---
but that concerns this corpus, not the situations the programme targets.

Must not be written as established: the superiority of the model; a significant
gap, since no independent trial exists to compute one; generality, H2 covering
one schema, one question and one model; a cost gain; the validity of the V0
threshold, which the gate does not apply; and the integrity of the corpus, the
official healthy control being absent from the catalogue.

\subsection{The blockage, and what would cross it}

The obstacle is not the measurement machinery, which is now sound, but the
material it would need: situations where the answer is not settled by a rule.
Table~\ref{tab:jusquou} states, for each blockage, the observable test that would
show it crossed. Three of its four rows depend on the first: a comparable arm, a
written reference automation and a corpus built for the question measure the
absence of that situation until one exists. \textbf{The first row is the only
work that can start today.}

\subsection{The three decisions}

\textbf{1. Trials.} Build trials that a one-line rule does not cross, applying the
filter that one hour of observation established, or publish a bounded
methodological result and declare it as such.

\textbf{2. The opening condition.} Write the competent reference automation that
D1+ names, or renounce explicitly the hypotheses that depend on it.

\textbf{3. The comparable arm.} Give the model the observations the rules already
receive, or state that the comparison measures verification rather than
interpretation.

These three decisions together determine whether an inference can one day exist.
None of them is technical in the narrow sense: all of them concern what one
accepts not to be able to say.

\section{Conclusion}

The system is built, instrumented and documented. Its chain of evidence is sound:
a separate oracle, an evaluator that recounts, a log that does not forgive a lost
piece of evidence, a safeguard that declares its blind spots. The defects found in
this report were found by reading what the code does, not what it claims, and that
is the best evidence that the verification discipline works.

The scientific question remains open. The programme asked when a model does better
than a script with identical tools; the available data do not answer it, and the
current arrangement would not allow an answer even with more machine time. The
next result the project can legitimately produce is \emph{a trial that survives its
closure test}, not a better score.
