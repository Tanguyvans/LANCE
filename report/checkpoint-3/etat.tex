\begin{abstract}
LANCE is a platform for auditing authorised connected-object networks with
language-model agents, inside a laboratory. A scenario is deployed, an agent audits
it, its evidence is archived, and what it found is scored against a ground truth.
Developed in the context of the UMONS work of the NATO SPS G6259 programme.

Its benchmark is built to compare what one wants to compare, under the same
conditions. This checkpoint documents one case, an automation against a model; the
comparison that would separate them is not yet possible.

Nothing counts as a result until the project can point to a case where a rule
written on one line gets the answer wrong and reasoning over several readings
gets it right. Without such cases, nothing else the project does counts.

The scientific position is unchanged since the previous checkpoint --- the platform
is built, instrumented and documented, its chain of evidence sound --- but the
method advanced: a closure test now precedes each challenge, the inference is
repaired, a reference H2 round was run, and a pilot challenge was built and rejected.
\end{abstract}
