# LumenField LF-60 — Technical Specifications

*Format: Product datasheet*

1. The LF-60 is an industrial IoT gateway designed for low-power sensor networks.
2. It supports Ethernet, LTE, and IEEE 802.15.4 connectivity.
3. The internal command queue accommodates operations for temporarily unavailable endpoints.
4. Each command is checked against the originating account's permissions when it is first accepted.
5. Accepted operations remain deliverable regardless of whether that account later retains its original authorization.
6. The device supports up to 1,000 registered endpoints.
7. The default network heartbeat is 60 seconds.
8. The management interface uses authentication tokens with a standard 12-hour lifetime.
