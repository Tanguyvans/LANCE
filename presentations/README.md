# Présentations

Supports de communication datés : progress reports, exposés, démonstrations.
Un dossier par présentation, nommé `AAAA-MM-JJ-<sujet>`.

Ce ne sont ni des études (celles-ci vivent dans [`research/`](../research/README.md)),
ni des contrats de fonctionnement ([`docs/`](../docs/README.md)), ni la ligne
directrice du projet ([`objectifs/`](../objectifs/README.md)). Une présentation
peut citer ces trois dossiers, mais elle ne fait pas autorité : en cas d'écart,
c'est la page de référence qui a raison.

## Contenu

| Dossier | Sujet | Sources |
| --- | --- | --- |
| [2026-10-23-progress-report](2026-10-23-progress-report/) | Progress report : objectif, architecture, benchmark V1/V2, sandbox, prochaines étapes | `slides/*.html` (deck), `slides.pdf`, `deck.json` |

Les sources du deck sont des fichiers HTML autonomes ; `slides.pdf` est l'export
daté. `variante-opus/` conserve une variante de composition non retenue.
